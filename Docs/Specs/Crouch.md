# しゃがみ・しゃがみ滑り仕様
## 前提
しゃがみは姿勢の軸（[MotionState.md](MotionState.md)）で、水平方向の移動モード（[Dash.md](Dash.md)）とは独立して持つ。
ダッシュ中にしゃがむと「しゃがみ滑り」になり、ダッシュの速度を保ったまま、摩擦で減速して止まる。

## 1. 確定仕様
### 1.1. しゃがみ
- スティックを下に倒している間、接地中ならしゃがむ。入力は、左右移動と同じ Move アクションの上下の値を使う。
- 倒すのをやめると立つ。頭上に天井があって立てないときは、しゃがんだままにする。
- 空中ではしゃがまない。空中の下入力は急降下（[MotionState.md](MotionState.md) 1.3）として扱う。着地したときに下入力が続いていれば、しゃがむ。
- しゃがんでいる間は、コライダーを低くする。高さは y だけを0.5倍にし、x は変えない。足元の位置が変わらないように、`offset` の y も合わせてずらす。
- コライダーは、しゃがむ移行が終わった後に小さくする。立ち上がるときも、解除が終わった後に元に戻す。
- しゃがむ移行と立ち上がる解除は、どちらも `TransitionSeconds`（とりあえず0.08秒）かける。
- 立ち上がれるかどうか（頭上に天井があるか）の判定は、解除の開始時に行う。
- 天井の判定は、接地判定（`isGrounded`）と同じように、設定した位置・大きさ・レイヤーで判定するクラス（`CeilingCheck`）を使う。
- しゃがんでいるとき（移行中・解除中を含む）は、ダッシュには入らない。
- ボタンの入力はスティック下だけで、ボタンは使わない。

### 1.2. しゃがみ歩き
- しゃがんだまま、低速で歩ける。
- しゃがむ移行中と立ち上がる解除中は、移動できない（水平速度は0にする）。

### 1.3. しゃがみ滑り
- ダッシュ状態で接地中にしゃがむと、しゃがみ滑りに入る。
- 入るときの速度は、ダッシュの速度のまま変えない。
- しゃがみ滑りにも、しゃがむ移行と同じ `TransitionSeconds` をかける。滑りは入った時点から始まり（速度は摩擦で減速する）、コライダーだけを移行が終わった後に小さくする。
- 最高速からの反転中（ブレーキ状態）にしゃがんだときは、そのときの速度で決める。歩行の最高速を超えていれば滑り、超えていなければ通常のしゃがみになる。ブレーキで速度が落ちるので、基本は通常のしゃがみになる。
- 滑っている間は、摩擦で減速する。速度が0になったら止まり、スティックを倒している間はしゃがみ（動かない）になる。滑る時間に制限はなく、摩擦（`SlideDeceleration`）だけで決まる。
- 滑っている間は、左右入力で向きを変えられない。速度も、左右入力で加速・反転しない（摩擦による減速だけ）。
- スティックを倒すのをやめたら立つ。天井があって立てないときは、滑りもしゃがみも続ける。
- 滑りを解除したとき、ダッシュの開始条件（[Dash.md](Dash.md) 1.1）を満たしていれば、ダッシュに移行できる。
  - 開始条件: 接地中、ダッシュボタンを押している、左右を倒している、現在の速度と同じ向き（逆向きなら移行しない）
  - 移行するときの速度は、減速した現在の値ではなく、ダッシュの基準速度（`DashEntrySpeed`）から入る。`DashEntrySpeed` はしゃがみ滑りの設定に置く
  - 満たしていないときは、歩きと同じ規則に従う（速度も歩きと同じ）
- ジャンプで滑りを中断できる。そのときの速度は維持する。中断後、ダッシュボタンを押していればダッシュ状態になり（空中のダッシュ）、押していなければ歩きの規則に従う。

### 1.4. 他の状態との関係
- 急降下: 空中だけの動きなので、しゃがみとは重ならない。
- ダッシュ: しゃがみ滑りに入ると、ダッシュ状態は解除する。滑りを解除するときに、ダッシュの開始条件を満たすとダッシュに戻れる。
- 向き: 滑り中は更新しない（[MotionState.md](MotionState.md) 2.5）。
- 敵: しゃがみ滑り中は当たり判定が小さくなるので、敵の攻撃を避けられる。攻撃判定は持たない（敵を倒せない）。
- ボディアタック: 空中だけの動きなので、しゃがみ中・滑り中には発動しない。ボディアタック中のコライダーは、しゃがみと共有する。着地で終わったときに天井があって立てないときは、しゃがみになる（[BodyAttack.md](BodyAttack.md)）。

### 1.5. スプライト
- しゃがみ・しゃがみ歩き・しゃがみ滑りは、すべて `PlayerCrouching` を使う。

## 2. 実装で決めた細部
仕様書にない細部。実装の判断をここに残す。

| 項目 | 決めたこと |
|---|---|
| しゃがむ移行中・解除中の速度 | 水平・垂直ともに0（接地中のみ起きる） |
| 滑りの移行時間 | 滑り自体は入った時点から始まり、コライダーだけを `TransitionSeconds` 後に縮める。移行中に止めると勢いが消えるため |
| ブレーキ中にしゃがんだときの境目 | 水平速度が歩きの最高速（`MoveSpeed`）以下なら通常のしゃがみ |
| 滑りを解除して天井があるとき | 解除に入らず、滑り（止まったらしゃがみ）を続ける |
| 空中に出たとき | すぐ立ちに戻し、コライダーも戻す（天井は見ない）。滑りの途中だった場合は、ダッシュボタンを押していれば空中でダッシュを再開する |
| 天井判定 | 床と同じレイヤー（`groundLayerMask`）に対する `OverlapBox`。立ち上がる解除の開始時にだけ見る |
| 設定の割り当て | `CrouchSettings` は必須（`null` を許さない） |

## 3. 実装
- 設定: `Scripts/Settings/CrouchSettings.cs`（アセット: `Data/CrouchSettings.asset`）
  - 既定値: `StickThreshold` 0.6、`WalkSpeedMultiplier` 0.4、`SlideDeceleration` 35、`DashEntrySpeed` 28、`TransitionSeconds` 0.08、`CrouchColliderHeightMultiplier` 0.5
- 状態と遷移: `Scripts/Abilities/Crouch.cs`（`CrouchState`、`CrouchTransition`）
- 天井判定: `Scripts/Abilities/CeilingCheck.cs`
- コライダーの縮小・復元: `Scripts/Abilities/ShrinkableCollider.cs`（ボディアタックと共有）
- 処理の順序と水平速度の優先順位: `PlayerMover.cs` の `FixedUpdate`（[MotionState.md](MotionState.md) 1.4）
