# 坂

## 前提
- 対象は三角形の床（30° と 45°）。
- 接地判定は [GroundCheck.cs](../../Assets/_Project/Features/Player/Scripts/Abilities/GroundCheck.cs) が行い、接触の法線は [PlayerMover.cs](../../Assets/_Project/Features/Player/Scripts/PlayerMover.cs) が `Rigidbody2D.GetContacts` で補う。
- 処理の順序は [MotionState.md](MotionState.md) 1.4 に従う。

## 1. 確定仕様
### 1.1. 対象の動き
- 30°・45° の斜面を、左右どちらの向きにも歩く・止まる・ジャンプする。
- 斜面の上で入力を離すと、その場で止まる。
- 上りから平面へ、平面から下りへ移る。浮かず、引っかからず、滑らない。

### 1.2. 接地
- 床とみなすのは、法線の Y が `minGroundNormalY`（0.7 ≈ 45.6°）以上の面だけ。ほぼ水平な壁は接地扱いにしない。45° の斜面は床とみなす。
- 足元の左・中央・右から短く下へ線を飛ばして床を探す。この3本のうち、最も平らな面を使う。
- 進行方向の先の足元からも1本飛ばす。採用するのは次の条件を満たす面だけ。
  - 登りの面（進行方向と逆に傾いている）
  - 今の床より急な面
  
  平らな面へ先に切り替えると、まだ斜面に触れているのに水平速度を向けてしまい、跳ねるため。
- 接触している床（`GetContacts`）のうち、最も急な面を使う。緩い面を使うと、頂点や折れ目で止まるため。
- ジャンプで上昇中は、足元が床に触れていても接地扱いにしない。ジャンプ直後の二重発動を防ぐため。
- 中央の線が床までの距離を測り、接触がなく隙間があるときだけ、足元を床まで下げる。接触中は動かさない。動かすと毎回めり込むため。

### 1.3. 移動
- 接地中の水平速度 `vx` は、床の接線に沿わせる。`vy = vx × 接線の傾き`。登りも下りも同じ式で、止まっているときは `vx = 0` で `vy = 0`。
- 空中では、接線への補正をしない。重力に任せる。
- 速度は直接書き換える。摩擦には頼らない。

## 2. 決まっていない仕様
- 凸の頂点（角）で、跳ねずに床へ乗り続ける条件。
- 下りの斜面で、足元の吸着をどこまで行うか（距離の上限）。
- 壁際の斜面（壁と床の折れ目）での扱い。

## 3. 実装
- 設定（`PlayerMover` の Inspector。シーン側の値はここで上書きされる）
  - `groundCheckSize`: 既定 (0.8, 0.05)。プレイヤー幅より少し狭い
  - `groundCheckDistanceUnits`: 既定 0.05。足元の下へ飛ばす距離
  - `groundCheckLiftUnits`: 既定 0.5。線の始点を足元より上へ上げる量。斜面の角が床に埋まった状態で始まらないようにする
  - `minGroundNormalY`: 既定 0.7
- 接地と先読み: `GroundCheck.TryGetGround`
- 接触・接地の確定・吸着: `PlayerMover.UpdateGroundedState`
- 接線への速度: `PlayerMover.UpdateSlopeVelocity`（ボディアタック中は行わない）

- 上りから平面へ移るときも跳ねる。
