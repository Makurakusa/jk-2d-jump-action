## A. 近代の2Dマリオ（NSMB DS / NSMBW）
### A.1. 速度（単位: ピクセル/フレーム）
| 状態 | 速度 | 出典 |
|---|---|---|
| 走り（通常の最高速） | 3.0 | NSMBW、NSMB DS |
| ジャンプ中（走りから） | 3.0 | NSMBW |
| スター | 4.0 | NSMBW |
| プロペラ回転（上昇 / 落下） | 2.5 / 1.5 | NSMBW |
| 甲羅回転 | 2.75 | NSMB DS |

- 歩き速度と加速度の数値は確認できていない。
- NSMBW では、走るには常に走りボタンを押し続ける。
- 仮に1ブロック = 16px、60fps とした概算（資料にはない計算値）: 走り 3.0 ≒ 11.25 ブロック/秒。

### A.2. ジャンプと速度（NSMBW）
- 地上でジャンプしても、水平速度は増減しない。
- 走って跳ぶと、停止から跳ぶより高く跳べる。段階的な閾値表は確認できていない。
- 速度3.0以上で、着地後8フレーム以内に再ジャンプすると連続ジャンプが成立する。
  - 最大高さ: 1回目・2回目が5ブロック、3回目が6ブロック。
- 下り坂は加速を助ける。ローリングヒルでは、数フレームだけ 6.0 を超える例がある。

### A.3. 現在の仕様との対応
| 現在の仕様（`Dash.md`） | 近代の2Dマリオ |
|---|---|
| ダッシュボタンを押しながら移動でダッシュ状態 | 同じ（NSMBW は走りボタンを押し続ける） |
| 着地時にダッシュ速度を維持 | 同じ発想（地上のジャンプで速度が増減しない） |
| ダッシュ中のジャンプ高さ上昇 | 走りジャンプは高い。数値は未確認 |
| 最速反転で 0.2 秒のブレーキ状態 | 資料なし（未確認） |

## B. SMB1（1985・古典、参考のみ）
対象は SMB1（NTSC）。近代の挙動とは大きく異なるため、仕様の根拠には使わない。

## B.1. 速度の扱い
- 水平速度 `Player_X_Speed` はゲームの変数。毎フレーム加速度を足し、上限で頭打ちにする。物理エンジンの力は使わない。
- 単位は サブピクセル/フレーム（16サブピクセル = 1ピクセル）。
- 壁に衝突すると速度を0にリセットする。

## B.2. 速度の上限
| 状態 | 上限 | 種類 |
|---|---|---|
| 歩き | ±24 | ソフトキャップ |
| 走り | ±40 | ハードキャップ |

- 走りは歩きの約1.67倍。
- ソフトキャップは、入力なしまたは逆入力のとき上限を超えた速度を保てる。減速は摩擦のみ。

## B.3. 走り状態
- 成立条件: Bを押している、地上にいる、進行方向へ入力している。
- 条件を満たす間は `RunningTimer` を10にリセットし、外れると毎フレーム1ずつ減る。
- 走り状態に入れるのは地上だけ。空中では維持され、着地しても速度は残る。
- `RunningSpeed` フラグは速度が28以上で立つ。解除は「入力方向が進行方向と同じ、かつ速度が28未満」のときだけ。

## B.4. 反転
- 進行方向と逆を向くと、加速度が2倍になる。
- 時間で区切るブレーキ状態はない。

## B.5. ジャンプ高さ
- 踏み切り時の水平速度（絶対値）を、閾値 9 / 16 / 25 / 28 で5段階に分ける。
- 段階ごとに初速と重力を切り替える（Mario の値）。

| 段階 | 水平速度 | 初速Y | 上昇重力 | 下降重力 |
|---|---|---|---|---|
| 0 | 9未満 | -4 | 0x20 | 0x70 |
| 1 | 9〜15 | -4 | 0x20 | 0x70 |
| 2 | 16〜24 | -4 | 0x1e | 0x60 |
| 3 | 25〜27 | -5 | 0x28 | 0x90 |
| 4 | 28以上 | -5 | 0x28 | 0x90 |

- 重力は 1/256 ピクセル/フレーム² 単位。
- 概算（資料にない計算値、高さ ≒ 初速² / 2 / 重力）: 段階0・1が約64px、段階2が約68px、段階3以上が約80px。走りのジャンプは約1.25倍高い。
